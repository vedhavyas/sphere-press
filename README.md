# Sphere Press site

Static landing page for the Sphere Press catalogue and the free 10-page sampler.

- `index.html` - the page (single file, inline CSS, no external dependencies)
- `covers/` - front-cover images cropped from the KDP wrap previews in the vault
- `assets/` - the free sampler PDF and its PNG zip
- `favicon.svg` - the site icon

Hosted with GitHub Pages from the `main` branch. Update by editing the files here and pushing to `main`.
